# PMX 汉化版 · 架构与设计系统文档

> 本文档定义本项目自 fork 后的模块划分与「初音绿（Miku）· MIUI X + Apple 现代混合」设计系统规范。
> 所有新增/修改代码必须遵循本文档，避免"缝缝补补"式散落改动。

## 一、设计系统资源模块（初音绿 Miku · MIUI X + Apple 现代混合）

设计系统完全集中在下述资源文件中，**任何布局/主题/Java 代码都禁止硬编码颜色值**：

| 文件 | 职责 |
|---|---|
| `res/values/colors.xml` | 颜色 Token（**浅色 = 默认模式**），按初音绿（Miku）分层：基底层 / 品牌层 / 文字层 / 语义层 / 控件层；品牌色唯一为 Miku 绿 |
| `res/values-night/colors.xml` | 夜间模式覆盖值（仅覆盖与浅色不同的 Token） |
| `res/values/dimens.xml` | 间距 Token（4/8/12/16/20/24/32dp）与圆角 Token（8/12/16/20/24/28/999dp）；布局一律引用，禁止写死 dp |
| `res/values/theme.xml` | `AppTheme`：windowBackground、双命名空间文字色桥接（`android:textColor*` 与 AppCompat `textColor*`）、对话框圆角/背景 |
| `res/values/styles.xml` | `BaseTheme`（品牌色 attr 绑定）、公共样式（按钮/分隔线）、主题色 overlay（`ThemeOverlayGreen` / `ThemeOverlaySystem`） |
| `res/values/attrs.xml` | 主题自定义属性（accentColor 等）+ AppCompat 桥接属性声明 |
| `res/drawable/card_bg*.xml` | 卡片背景（圆角 + 弱边框），引用 Token 自动双模式 |
| `res/drawable/search_bg.xml`、`capsule_fill/outline.xml`、`chip_bg.xml` | 搜索框 / 胶囊按钮 / AppOp chip 背景 |

### 双模式机制

- 主题 `Theme.AppCompat.DayNight` + `values/values-night` 资源覆盖 → 随系统/应用设置自动切换。
- 主题设置（主题色 + 夜间模式）→ 夜间模式三档（跟随系统/浅色/深色）由 `BaseActivity.setNightTheme()` 应用。
- 主题色固定为两个选项：**初音绿 green（默认）** / **跟随系统 system（动态取色）**，由 `BaseActivity.applyThemeColor()` 应用对应 `ThemeOverlay*`。
- 旧版外观开关（卡片风格 / 圆角 / 列表密度 / 水波纹 / 引用指示条 / AppOp chip / 大标题）已全部移除，`UiPrefUtils` 现固定返回新设计风格，不再读取用户偏好。
- **新增颜色必须同时考虑两模式**：语义色/品牌色放 `values`；背景/文字类 Token 必须在 `values-night` 提供深色值。

## 二、Java 模块划分

```
com.mirfatif.permissionmanagerx
├── app/           应用入口（App）
├── base/          基础 Activity/Dialog（主题与夜间模式应用）
├── main/          主界面（应用列表）—— 外观一律通过 zhx.design.UiPrefUtils 读取
├── pkg/           单应用页（权限列表）
├── parser/        数据解析层：PackageParser / Permission / Package
├── privs/         守护进程交互（DaemonIface / DaemonHandler）
├── prefs/         设置（MySettings / SettingsFragTheme）
├── fwk/           系统兼容薄包装（*ActivityM；zhx 页面也走此模式）
└── zhx/           ★ 汉化版功能模块（本项目的全部自研代码集中于此）
    ├── design/    【设计/外观模块】UiPrefUtils：外观唯一读取入口；UI 全面改版后
    │              固定新设计风格（卡片背景/水波纹/引用指示条/AppOp chip/大标题固定开启），
    │              不再读取用户外观偏好（相关开关已移除）
    ├── i18n/      【汉化模块】PermDescProvider：权限中文名+说明+规则翻译
    │              （系统本地化名 → 内置映射 → 规则翻译三级兜底）唯一入口
    └── permview/  【权限视图模块】PermListView（按权限聚合数据层）+
                   PermListActivity（权限列表页）+ PermAppsActivity（应用列表页）
```

### 模块规则

1. **官方文件只允许"集成钩子"**：官方包内文件对 zhx 的引用仅限于 import + 单点调用
   （PackageParser 两处 rebuild/两处 getLabel、两个 Adapter 的 UiPrefUtils 调用、
   菜单入口），不得在官方文件里散落实现新功能。
2. **外观**：任何界面要应用外观，只允许调 `zhx.design.UiPrefUtils`（改版后返回固定值，不再读取用户偏好）。
3. **颜色**：Java 侧取色统一用资源引用，禁止硬编码颜色常量做 UI 配色（文字高亮动态混合除外）。
4. **权限中文名/说明**：统一走 `zhx.i18n.PermDescProvider`，其它代码不得自造映射。
5. **权限视图**：页面与数据层都在 `zhx.permview`；权限修改后必须经 `PackageParser.updatePkgList()` 触发重解析刷新。
