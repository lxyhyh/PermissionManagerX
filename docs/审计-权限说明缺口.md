# 审计：权限说明缺口 2026-08-13

## 现状排查结论
1. **应用内不显示任何权限描述文字**：Java 源码中无 `loadDescription`/`getDescription` 调用；权限详情只显示名称、标志（保护级别）、状态、模式、最后访问时间等。
2. `about_dump_title`（"转储信息"）的说明"导出缺少的权限图标、名称和描述"——该功能属于 Pro/调试侧，FOSS 代码中未见实现。
3. 帮助站 `help/permission-references/` 只解释"权限引用"功能本身，**不是**逐条权限的说明字典。
4. 结论："有些权限没解释"= **应用内浏览 AppOps / 清单权限时没有任何中文解释**，且帮助站也没有逐条说明。这是一个真实缺口。

## 缺口规模
- AppOps 全集：约 100+ 个 op（系统 `OP_*` 常量，随 Android 版本增长，如 CAMERA、READ_CONTACTS、RUN_IN_BACKGROUND、REQUEST_INSTALL_PACKAGES、SYSTEM_ALERT_WINDOW…）。
- 常用清单权限（Manifest）：约 150+ 条（危险级+常用特殊级，如 READ_SMS、ACCESS_FINE_LOCATION、BIND_DEVICE_ADMIN…）。

## 落点方案（待用户确认）
### 方案 A：应用内补说明（改 Java + 资源）
- 在 `values-zh-rCN` 新增 `app_op_descs.xml` + `perm_descs.xml`（op 名/权限名 → 中文说明映射）。
- 在权限详情对话框（`PackageActivity`/权限行详情逻辑）加一行"说明"展示；查不到则隐藏。
- 优点：手机里直接看到；缺点：要动 Java/布局，构建风险中等。

### 方案 B：帮助站补"权限说明大全"页（只改 help/）
- 在 `help/zh/` 新增 `permission-reference-list/`（或并入现有 permission-references 页），逐条列出 AppOps 与常用清单权限的中文说明。
- 配合 fork 的 GitHub Pages 生效（见《审计-帮助文档.md》第三节）。
- 优点：不动 Java，零构建风险；缺点：要点开帮助才能看。

### 方案 C：A + B（应用内简版 + 帮助站大全）
- 应用内给**高频 AppOps**（约 30 条：相机、麦克风、定位、后台运行、剪贴板、悬浮窗、安装包…）加一句话说明；
- 帮助站放**全集大全**。
- 工作量最大但体验最完整。

## 权限说明数据来源建议
- AppOps 说明：依据 Android 官方 AppOpsManager 常量语义 + AOSP `appops` 命令文档，逐条编写中文说明（模式含义+典型影响）。
- 清单权限说明：依据 Android 官方 Manifest.permission 文档逐条翻译编写。
- 说明风格：每条 1-2 句话，说明"管什么、被滥用会怎样"，附模式建议（如 RUN_IN_BACKGROUND 建议设为"仅前台"）。
