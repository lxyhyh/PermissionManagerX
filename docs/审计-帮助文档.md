# 审计：帮助文档（help/zh）2026-08-13

审计范围：`help/zh/` 共 **12 个 HTML 页面**（MkDocs 构建产物，每页约 28-68KB，其中绝大部分是共享导航/侧栏）。

## 一、机翻痕迹（确定存在，需全文重写）
- 导航栏：`评分/评论/评论/更新/星星` ← 原文 "Ratings / Reviews / Updates / Stars"
- 导航栏：`恒星`（应作"加星/星标"）、`援助功能`（应作"付费功能"）、`许可参考`（应作"权限引用"）
- 首页正文：`免费审判`（应作"免费试用"）、`令人惊奇的是？`（"想知道更多？"）、`更多的东西`（"更多内容"）
- 首页正文：`无法从系统设置中修改的权限由很多`（原文 "There are many permissions which cannot be modified from system settings"，句子被截断错译）
- 术语混乱：`前景`（Foreground，应作"仅前台"）、`应用程序操作/应用操作` 与 AppOps 混用、`清单权限/显式权限/许可` 与 Manifest 权限混用
- 中英夹杂缺空格：`使用 PMX 与 ADB`、`将应用程序与ADB配对/连接`、`Android 常见问题` 等
- details/index.html 存在成段英文残留（未翻译段落）

## 二、重写方案
1. 以英文版 `help/*.html` 为对照，逐页重写 `help/zh/` 12 个页面的**正文内容区**（`<article>`/main 部分），并统一导航术语。
2. 保持 HTML 结构、锚点、图片路径不变（避免破坏站内链接）。
3. 统一术语：AppOps（不译）、Manifest 权限=清单权限、Reference=引用、Foreground=仅前台、Ignore=忽略、Deny=拒绝、Granted=已授予、Revoked=已撤销、Profiles=配置文件、Watcher=监视器。
4. 目录命名：站点实际以 `zh` 为目录（`/help/cn/` 也能访问，暂不改 `help_dir_name`）。
