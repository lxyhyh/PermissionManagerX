## 二、术语不统一（需全文统一）

| 术语 | 现状 | 统一为 |
|---|---|---|
| reference(s) | 模板 / 引用 / 参考 三种混用 | **引用**（与官方中文帮助"权限引用"一致） |
| preference(s) | 模板 / 首选项 / 偏好 混用 | **偏好设置** |
| package(s) | 应用 / 软件 / 软件包 混用 | **应用** |
| restore | 恢复 / 还原 混用 | **恢复** |
| Privileges（特权页） | 与"权限"(Permissions)混用 | **特权** |
| AppOp/AppOps | AppOp / AppOps / 应用操作 混用 | 统一 **AppOps**（业界通用，不译） |
| 省略号 | "..." 与 "…" 混用 | 统一 **…** |
| 中英文间空格 | "Root权限"/"Root 权限" 混用 | 英文词前后留半角空格 |
| 标点 | 英文逗号", "与中文"，"混用 | 统一中文标点（%，AppOps 等除外） |
